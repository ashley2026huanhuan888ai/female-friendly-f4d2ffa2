# Canvas 渲染器排版稳健化

Canvas 输出宽度固定 1080px，不受手机视口影响；但当温度数字、°C 单位、长标签出现时仍可能挤出右边界。集中处理以下溢出场景：

## 改动（仅 `src/lib/exportCanvas.ts`）

**温度条 + 数字不溢出**
- 先按字号测量 `tempStr + °C` 的总宽度，动态计算温度条宽度：`barW = W - PAD*2 - (tempBlockW + 24)`，下限 320。
- 三位数（如 `100`）字号降到 72；两位数保持 84；超长 fallback 自动缩到能容纳为止。
- 温度数字与 °C 用同一 baseline，避免 baseline 偏移导致单位被裁。

**标签不溢出**
- 单个标签宽度 > 可用宽度时按字符截断并加 `…`。
- 标签换行算法用真实测量 + 行高 32，最多 3 行，超出折叠 `+N`。
- 标签字号在窄场景（标签数 ≥ 6 或最长标签 ≥ 8 字符）自动从 22 降到 20。

**正文 / 摘要换行更稳**
- `wrapText` 增加对超长无空格英文/URL 的强制断字（当单字符宽度仍超过 maxWidth 时跳过避免死循环）。
- 行高比例统一：摘要 1.35、正文 1.65、标签 1.45（之前 1.4 / 1.7 / 28px 硬编码）。

**页脚导出者名称溢出**
- 测量 `nowText + exporterName` 与右侧对象名总宽，若超过 `W - PAD*2 - 24`，将左侧文字截断加 `…`，保证不重叠。

**总高度测量与绘制保持一致**
- 测量阶段使用与绘制完全相同的字号 / 行高常量（抽成 `TYPO` 常量对象），避免高度算少导致底部内容被切。

## 不改动
- 卡片宽度 1080、PAD 64、字体栈、温度色逻辑。
- DOM 预览 (`ExportCardDialog.tsx`) 不变。

## 验证
Playwright 触发 3 组场景导出 PNG 并截图核对：
1. 温度 100、长对象名、5 个长标签
2. 温度 7、单标签、超长 URL 正文
3. 多 observation + 截图混排
