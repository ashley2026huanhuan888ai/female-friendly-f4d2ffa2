# 导出卡手机阅读性优化

## 问题
导出 PNG 固定 1080px 宽，分享到手机后被缩放到 ~390px（约 0.36×），导致正文 26px 实际显示仅 ~9px，几乎无法阅读。所有辅助文本（标签、日期、页脚、副标题、扫码说明）同样过小。

## 思路
保持 1080 宽度（兼容长图分享），整体把字号「放大一档」，按手机缩放后的目标可读尺寸反推：

| 元素 | 现 | 改 | 手机显示(≈0.36×) |
|---|---|---|---|
| 正文 body | 26 | **38** | 13.7px |
| 摘要 summary | 30 | **46** | 16.6px |
| 标签 tag | 22/20 | **34/30** | 12.2px |
| 场景 scene | 13 | **20** | 7.2px → 改 18 + 字重 500 |
| 日期 date | 13 | **20** | |
| 页脚 footer | 14 | **22** | 7.9px |
| 卡标题 cardTitle | 38 | **44** | |
| 副标题 cardSubtitle | 15 | **20** | |
| 类型 pill | 16 | **20**（pill 高 26→32） | |
| 档案号 archiveNo | 15 | **20** | |
| 扫码说明 scanToView | 12 | **18** | |
| 温度数字 | 84/68 | 96/80 | 已够大，微调 |
| 温度单位 °C | 28 | 34 | |
| 对象名 name | 84/68/56/48 | **72/60/52/44** | 缩一档让出版面 |

## 间距同步调整
- 标签行高 `tagLH` 32 → 44
- 摘要 `summaryLH` 1.35、正文 `bodyLH` 1.65 保持比例
- 段落下间距 16 → 20，块底 padding 36 → 40
- 标签宽密阈值：tags≥5 或 maxLen≥9 触发降档

## 改动范围
- 只改 `src/lib/exportCanvas.ts` 的 `TYPO` 常量与对应数值
- DOM 预览 `ExportCardDialog.tsx` 不动（预览本就在桌面对话框中尺寸合适）

## 验证
Playwright 加载 preview，模拟导出 → 把 PNG 缩放到 390px 宽截图比对，正文与标签清晰可辨。
