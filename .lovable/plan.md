# 导出卡移动端布局优化

## 目标
1. 标签（#tag）从正文上方移到温度条上方，与对象名水平/紧邻；颜色统一为温度色（`bandHex`）
2. 卡片整体适配全屏手机比例：宽度按手机（保持 1080px 基准），高度自适应内容
3. 字体大小整体重新校准，避免手机预览时过大/过小

## 改动点

**位置：标签上移**
- DOM 预览（`src/components/ExportCardDialog.tsx`）和 Canvas 渲染（`src/lib/exportCanvas.ts`）同步
- 标签行渲染在「对象名 + 温度条」区块顶部，温度条上方一行
- 标签颜色（含 `#` 前缀和文字）从 `ACCENT`（粉）改为 `input.bandHex`（温度色）
- 原正文区域上方的标签行删除

**尺寸：手机宽度基准**
- Canvas 宽度由现 1080 改为标准手机基准（保留 1080，DPR≥2 即等效 iPhone 1170 物理像素），高度仍按内容动态计算
- 容器 padding 收紧（PAD 72 → 56），让内容利用率更高
- 预览 Dialog 内的 `.export-card` 容器以手机视口比例显示（max-width ~ 430px CSS，scale 缩放）

**字体重校**
- 对象名 92/76/60 → 84/68/56（长名更友好）
- 正文摘要 32 → 30，正文 24 → 26，行高 1.8 → 1.7
- 标签 18 → 22（上移后需更显眼）
- 温度数字 72 → 84，标题 38 → 36，副标题 15 → 14
- 页脚 14 → 13

## 验证
- Playwright 截 mobile 预览 + 导出 PNG，确认：标签在温度条上方、颜色为 #C95A3F 系（band 色）、整卡比例适配手机不被裁切
